# IMPERIUM — mobil strateji alfa

Çevrimdışı çalışan HTML5 strateji prototipi. Web sürümünü `index.html` dosyasını açarak deneyebilirsiniz.

## Android APK derleme
1. GitHub deposunda **Actions** sekmesini açın.
2. **Build IMPERIUM Android APK** iş akışını seçin.
3. **Run workflow** düğmesine basın.
4. İşlem tamamlanınca çalışmanın altındaki **Artifacts** bölümünden `imperium-android-debug-apk` dosyasını indirin.
5. ZIP içindeki `app-debug.apk` dosyasını Android telefonda açın.

Her `index.html` veya `android/` değişikliğinde APK otomatik olarak yeniden derlenir.

## Mevcut alfa sınırları
Bu sürüm harita, temel devlet yönetimi, ordu/kuşatma, diplomasi, hanedan ve çizim tabanlı saray odası prototipini içerir. Saray henüz gerçek 3D değildir; tüm medeniyetler için tarihsel doğruluk ve kapsamlı veri tabanı tamamlanmış değildir.
