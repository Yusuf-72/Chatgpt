# IMPERIUM — mobil strateji alfa

Çevrimdışı çalışan HTML5 strateji prototipi. Oyunu `index.html` dosyasını açarak deneyebilirsiniz.

Android APK için GitHub Actions sekmesinde **Build IMPERIUM Android APK** iş akışını çalıştırın. Başarılı derleme sonrası `imperium-android-debug-apk` artifact'ini indirin.

Not: Bu erken alfa; tüm medeniyetleri, gerçekçi 3D saray keşfini veya tam tarihsel veri tabanını henüz içermez.
